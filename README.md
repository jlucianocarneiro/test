# Guia Gramado 2026

PWA com o roteiro hora a hora da viagem a Gramado/RS (24–31/10/2026): timeline por dia, checklist, guia IA local, clima (Open-Meteo) e distâncias por GPS.

## Publicar no GitHub Pages

1. Em **Settings → Pages**, escolha *Deploy from a branch*, a branch com estes arquivos e a pasta `/ (root)`.
2. Abra `https://<usuario>.github.io/<repo>/` no celular.
3. Instale: Safari → Compartilhar → *Adicionar à Tela de Início*; Chrome → ⋮ → *Instalar app*.

## Clima e GPS

Na versão do GitHub Pages (HTTPS próprio) clima e GPS funcionam normalmente.
Dentro do artefato do claude.ai a página roda num iframe com sandbox: o clima mostra a média típica de outubro (8°–18°C) e a aba Local permite escolher o ponto atual numa lista para calcular as distâncias.
